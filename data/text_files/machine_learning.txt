Machine Learning Basics

    Machine learning is a subset of artificial intelligebce that enables systems to learn and improve
    from the experience without being explicity programmed. It focuses on developing computer
    programs that can access data and use it to learn for themselves.

    Types of Machine Learning:
    1. Supervised Learning: Learning with label data
    2. Unsupervised Learning: Finding patterns in unlabeld data
    3. Reinforcement Learning: Learning through rewards and penalities

    Applications include image recognition, speech processing, and recommendation systems.
